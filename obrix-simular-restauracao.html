Simular recuperação dos dados

Esta ferramenta lê o backup JSON e reconstrói seus registros somente na memória deste aparelho. Ela não se conecta ao Supabase, não cria empresas e não altera obras, pagamentos ou fotografias.

No aplicativo de teste do OBRIX, abra Menu → Backup → Gerar backup completo. Se já tiver um arquivo OBRIX_BACKUP_COMPLETO_....json, selecione-o aqui.

O inventário ajuda a cruzar os registros das fotos com os caminhos salvos. Os 10 ZIPs já verificados não precisam ser carregados novamente.

Selecione o arquivo JSON do backup para iniciar.

Limites desta etapa

Este teste avalia estrutura, contagens, vínculos e valores do JSON. Mesmo com resultado positivo, ele não equivale a uma restauração executada no PostgreSQL. As contas de acesso, assinaturas e arquivos físicos do Storage exigem procedimentos próprios.

O teste real de restauração deverá ocorrer posteriormente em um projeto Supabase separado, com confirmação do custo e sem apontar para a produção.

OBRIX · Teste isolado · Os arquivos selecionados não são enviados para nenhum servidor.
