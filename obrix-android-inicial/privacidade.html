Política de Privacidade — OBRIX

OBRIX — Gestão de Obras e Reformas.

Resumo: o OBRIX trata apenas os dados necessários para autenticação, gestão de obras, equipe, financeiro, estoque, relatórios, backup e assinatura.

1. Dados tratados

O OBRIX pode tratar dados de conta e perfil, dados da empresa, obras, clientes, equipe, diárias, faltas, vales, bônus, pagamentos, financeiro, estoque, checklists, diário de obra, orçamentos e documentos inseridos pelo usuário.

2. Finalidades

Os dados são usados para autenticação, sincronização entre dispositivos, funcionamento dos módulos do aplicativo, geração de relatórios, backup, recuperação, suporte e administração da assinatura.

3. Armazenamento e fornecedores

O OBRIX utiliza serviços em nuvem para autenticação, banco de dados e sincronização. Integrações de pagamento são processadas pelos respectivos provedores; dados completos de cartão não são armazenados pelo OBRIX.

4. Segurança

O acesso aos dados usa autenticação e regras de acesso por empresa. O usuário deve manter suas credenciais protegidas.

5. Compartilhamento

O OBRIX não foi projetado para vender dados pessoais. Dados podem ser processados por fornecedores necessários ao funcionamento do serviço.

6. Exportação e exclusão

O usuário pode exportar dados pelos recursos de backup e solicitar a exclusão da conta e dos dados associados pelas configurações do OBRIX.

7. Retenção

Algumas informações podem ser mantidas pelo período necessário para cumprimento de obrigações legais, prevenção de fraude, resolução de disputas ou deveres aplicáveis.

8. Atualizações

Esta política poderá ser atualizada quando o OBRIX alterar os tipos de dados tratados, fornecedores ou finalidades do tratamento.
